# Даша и Женя — приглашение в стиле 90-х

Гостевая ссылка: https://vikkiwwats.github.io/vikportfolio/wedding-90s/

Самостоятельный статический сайт: HTML, CSS, JavaScript и все изображения находятся в этой папке. Сервер, аккаунт ChatGPT и внешние сервисы для работы приглашения не нужны.

Главный экран: `index.html`, `style.css`, `hero-party.css`. Персонажи: `characters.js`. Интерактивность: `app.js`. Изображения: `assets/`. Дата праздника: 31 октября 2026, 17:00, Минск.

Досье выбираются случайно без повторов за круг; состояние хранится только в браузере гостя. Музыка включается по нажатию. Предусмотрен режим уменьшения движения.
